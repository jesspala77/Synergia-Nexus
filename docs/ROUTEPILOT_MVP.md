# RoutePilot MVP v1.0

## Product promise

RoutePilot helps delivery drivers finish routes faster by combining route organization, map-based clustering, shared location intelligence, and live progress tracking.

## Locked MVP scope

### 1. Route dashboard

Show:

- Route date
- Package count
- Unique stop count
- Completed and remaining packages
- Start time
- Starting mileage
- Current mileage
- Estimated finish time
- Apartments, gated communities, businesses, and houses
- Stops requiring access assistance
- Weather risk flag

### 2. Route map

- Plot every unique delivery location.
- Group nearby stops into clusters.
- Use one marker for multiple packages at the same address.
- Show stop status on the map.
- Allow opening the next stop in Apple Maps.

### 3. Stop detail

Store:

- Shipment number
- Recipient
- Full address
- Apartment or unit
- Telephone number
- Gate or call-box code
- Building name
- Business hours
- Parking instructions
- Entrance instructions
- Elevator or stair notes
- Delivery priority
- Recommended time window
- Driver notes
- Shared location notes

### 4. Stop statuses

- Pending
- In progress
- Completed
- Retry later
- Undeliverable

### 5. Route intelligence

Flags:

- Apartment
- Gated community
- Business
- Mobile-home park
- Multi-package address
- Access problem
- Closing soon
- Prioritize early
- Do last
- Weather-sensitive

### 6. Driver workflow

1. Import route.
2. Confirm route totals.
3. Enter start time and starting mileage.
4. Review clusters and critical stops.
5. Start the recommended first cluster.
6. Complete stops and capture notes.
7. Recalculate remaining ETA after each cluster.
8. Enter ending mileage and finish time.

## Deferred until after field testing

- Dispatcher portal
- Payroll
- Fleet maintenance
- Billing
- Enterprise analytics
- Public driver marketplace
- Full automated screenshot OCR

## First validation target

Use RoutePilot on one real route and confirm that it can:

- represent the full package count,
- prevent duplicate-address errors,
- make route order easier to follow,
- preserve access information,
- and produce a reliable completion estimate.
